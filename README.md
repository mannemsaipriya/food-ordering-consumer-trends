# Food Ordering Behaviour & Consumer Trends Dashboard

An interactive Tableau dashboard analyzing customer ordering habits, average order values, and cuisine trends across major cities.

## 🔗 Live Project
👉 **[View the Interactive Dashboard on Tableau Public](https://public.tableau.com/app/profile/sai.priya.mannem/viz/FoodOrderingBehaviourAnalysis/Dashboard1?publish=yes)**

![Dashboard Preview](dashboard-preview.png)

## 💡 Key Features Analyzed
* **City Insights:** Average order values mapped across locations like Bangalore, Delhi, and Mumbai.
* **Consumer Trends:** Analysis of popular cuisines (Biryani, North Indian, Chinese) relative to order frequency.
* **Weather Impacts:** Tracking how rainy weather affects regional food ordering habits.
